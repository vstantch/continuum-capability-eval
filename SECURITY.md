# Security Policy

This repository is a research artifact: a reference implementation and the
scripts that produce a paper's measurements. It is not an authorization
library and is not supported for production use.

## Reporting

A flaw in the verifier or the correctness vectors matters here, because the
vectors are the oracle the paper's results rest on. Report it privately via
GitHub private vulnerability reporting ("Security" tab, "Report a
vulnerability") or by email to stantchev@computer.org. Please do not open a
public issue for it. Expect an acknowledgement within seven days.

## Supported versions

Only the latest commit on `main` and the tag cited by the paper.
